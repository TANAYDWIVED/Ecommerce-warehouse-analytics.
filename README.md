# E-commerce Warehouse Analytics Dashboard

An end-to-end data analytics project using Excel and SQL to analyze warehouse operations, delivery performance, product categories, returns, and inventory risk.

## Tools Used
- Excel
- SQL
- Data Cleaning
- Data Analysis
- Data Visualization

## Key Results
- Analyzed 20,001 cleaned orders from January to August 2026.
- Gross order value: ₹67.5 million.
- Delivery delay rate: 79.1%.
- WH-Central had the highest delivery delay rate at 82.7%.
- WH-West had the highest return rate at 5.0%.
